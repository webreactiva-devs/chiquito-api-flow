# Chiquito API Flow
## Codebase Onboarding Presentation

**Architecture Overview & Development Guide**

---

## Executive Summary

- **Purpose**: REST API serving Chiquito de la Calzada jokes
- **Tech Stack**: Node.js 21+ | Express.js | ES Modules
- **Data**: 17 jokes across 5 categories (JSON-based)
- **Testing**: Node.js built-in test runner + Supertest
- **Tooling**: Biome for linting/formatting

---

## Project Architecture

```
src/
├── app.js       # Express routes & business logic
└── server.js    # Server bootstrap

data/
└── chiquito.json # Jokes database

tests/
└── app.test.js   # Test suite (100% endpoint coverage)

docs/
├── openapi.yml   # API documentation
└── *.md         # Onboarding docs
```

## API Endpoints Overview

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/health` | GET | Health check with themed response |
| `/api/jokes` | GET | All jokes (supports `?category=` filter) |
| `/api/jokes/random` | GET | Random joke selection |
| `/api/jokes/:id` | GET | Specific joke by ID |
| `/api/categories` | GET | Categories with joke counts |

## Key Code Patterns

### Data Loading Pattern
```javascript
const dataPath = join(__dirname, "../data/chiquito.json");
const { jokes } = JSON.parse(readFileSync(dataPath, "utf8"));
```
- Synchronous loading at startup
- In-memory caching for performance
- Single source of truth

---

## Key Code Patterns (cont.)

### Dynamic Category Aggregation
```javascript
const buildCategoriesWithCount = (jokesData) => {
  const categoryCount = {};
  jokesData.forEach((joke) => {
    categoryCount[joke.category] = (categoryCount[joke.category] || 0) + 1;
  });
  return Object.entries(categoryCount).map(([name, count]) => ({ name, count }));
};
```
